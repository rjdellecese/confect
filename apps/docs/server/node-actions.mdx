Node actions are like regular actions, but they are executed in the Node.js runtime, so their handlers can use Node's built-in modules and npm packages that depend on them. You declare a node action group by building its spec with `GroupSpec.makeNode()` (rather than `GroupSpec.make()`); that marks the group as Node-runtime, and Confect adds Convex's [`"use node"`](https://docs.convex.dev/functions/runtimes#nodejs-runtime) directive to the generated module accordingly. A node action group is otherwise an ordinary group—the same colocated `.spec.ts`/`.impl.ts` files, following the same [naming and nesting conventions](/concepts/file-naming-conventions).

## Node Spec

A Node spec uses `GroupSpec.makeNode()`. Define Effect-backed actions with `FunctionSpec.publicNodeAction` or `FunctionSpec.internalNodeAction`. For [plain Convex actions](/server/plain-convex-functions), use their `convexPublicNodeAction` or `convexInternalNodeAction` counterparts.

```ts confect/email.spec.ts
import { FunctionSpec, GroupSpec } from "@confect/core";
import * as Schema from "effect/Schema";

export default GroupSpec.makeNode().addFunction(
  FunctionSpec.publicNodeAction({
    name: "send",
    args: () => ({
      to: Schema.String,
      subject: Schema.String,
      body: Schema.String,
    }),
    returns: () => Schema.Null,
  }),
);
```

## Node Impl

An Effect-backed Node impl uses the generated `FunctionImpl` builder. Its handler runs in Node.js, so it has access to `NodeServices` from the `@effect/platform-node` package (filesystem, path, child processes, and more). If the spec declares only plain Convex actions, export the registered actions by name from the same `.impl.ts` file instead.

```ts confect/email.impl.ts
import { GroupImpl } from "@confect/server";
import * as Console from "effect/Console";
import * as Duration from "effect/Duration";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import * as ChildProcess from "effect/process/ChildProcess";
import { ChildProcessSpawner } from "effect/process/ChildProcessSpawner";
import { FunctionImpl } from "./_generated/server";
import email from "./email.spec";

const send = FunctionImpl.make(
  email,
  "send",
  Effect.fn(function* ({ to, subject, body }) {
    const spawner = yield* ChildProcessSpawner;
    const result = yield* spawner
      .string(
        ChildProcess.make("echo", [
          `Sending email to ${to} with subject ${subject} and body ${body}…`,
        ]),
      )
      .pipe(Effect.orDie);

    yield* Console.log(result);
    yield* Effect.sleep(Duration.seconds(1));
    yield* Console.log("Email sent!");

    return null;
  }),
);

export default GroupImpl.make(email).pipe(
  Layer.provide(send),
  GroupImpl.finalize,
);
```

## Calling Node Actions

Node actions are referenced like any other function. A node group at `confect/email.spec.ts` is reached at `refs.public.email`.

```ts
import { useAction } from "@confect/react";
import refs from "../confect/_generated/refs";

const sendEmail = useAction(refs.public.email.send);

sendEmail({
  to: "user@example.com",
  subject: "Hello",
  body: "Hello from Confect!",
});
```
