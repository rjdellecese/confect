icon: "cog"
title: "System Tables"
description: "Query system tables using the same API as regular tables."
---

Use the built-in handles from `@confect/server/Table` with `DatabaseReader` to read Convex's system tables. They contain file and scheduled-function metadata and cannot be passed to `DatabaseWriter`.

```ts
import * as Table from "@confect/server/Table";

reader.table(Table.storageTable).get(storageId);
reader
  .table(Table.scheduledFunctionsTable)
  .index("by_creation_time", "desc")
  .take(10);
```

For name-only operations, use the Convex table names as before: for example, `Id("_storage")` or `documentIds.parse("_scheduled_functions", input)`.
