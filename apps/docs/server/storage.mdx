Use the `Storage` service for file storage in queries, mutations, actions, and HTTP actions. Import it from your generated services module:

```ts
import * as Effect from "effect/Effect";
import { Storage } from "./confect/_generated/services";

Effect.gen(function* () {
  const storage = yield* Storage;

  return yield* storage.getUrl(storageId);
});
```

The service is available in every context, but each operation retains Convex's context restrictions. Confect checks these requirements when you implement a function or middleware.

| Operation               | Returns    | Available in                                  |
| ----------------------- | ---------- | --------------------------------------------- |
| `getUrl(storageId)`     | `URL`      | Queries, mutations, actions, and HTTP actions |
| `generateUploadUrl`     | `URL`      | Mutations, actions, and HTTP actions          |
| `delete(storageId)`     | `void`     | Mutations, actions, and HTTP actions          |
| `get(storageId)`        | `Blob`     | Actions and HTTP actions                      |
| `store(blob, options?)` | Storage ID | Actions and HTTP actions                      |

Every operation returns an Effect. The table lists the value produced when it succeeds.

## Get a download URL

<ContextBadges query mutation action http />

Retrieve a blob's download URL with `getUrl`. The result is a `URL` object, not a string. If the blob doesn't exist, the effect fails with `BlobNotFoundError`.

```ts
Effect.gen(function* () {
  const storage = yield* Storage;
  return yield* storage.getUrl(storageId);
});
```

## Generate an upload URL

<ContextBadges mutation action http />

Generate a URL that a client can use to upload a blob. `generateUploadUrl` is an Effect property, so yield it without parentheses. It produces a `URL` object.

```ts
Effect.gen(function* () {
  const storage = yield* Storage;
  return yield* storage.generateUploadUrl;
});
```

## Delete a blob

<ContextBadges mutation action http />

Delete a stored blob by its storage ID. If deletion fails, the effect fails with `BlobNotFoundError`.

```ts
Effect.gen(function* () {
  const storage = yield* Storage;
  yield* storage.delete(storageId);
});
```

## Get a blob

<ContextBadges action http />

Read a stored file directly as a `Blob`. If the blob doesn't exist, the effect fails with `BlobNotFoundError`.

```ts
Effect.gen(function* () {
  const storage = yield* Storage;
  return yield* storage.get(storageId);
});
```

## Store a blob

<ContextBadges action http />

Store a `Blob` directly and receive its storage ID. Optionally supply a SHA-256 hash in `options` for Convex to verify.

```ts
Effect.gen(function* () {
  const storage = yield* Storage;
  return yield* storage.store(blob);
});
```

```ts
Effect.gen(function* () {
  const storage = yield* Storage;
  return yield* storage.store(blob, { sha256: expectedHash });
});
```
