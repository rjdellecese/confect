description: "Schedule recurring tasks with cron jobs."
---

Define cron jobs in `confect/crons.ts` using `CronJob` and `CronJobs` from `@confect/server`. Each job has a unique identifier, a schedule, and a ref to an internal mutation or action.

Schedules can be an Effect [`Cron`](https://effect.website/docs/scheduling/cron) (cron expression), a [`Duration`](https://effect.website/docs/data-types/duration/) (fixed interval), or a `CronWindow` (a recurring hour in which Convex chooses the minute). The Confect CLI re-exports the result into `convex/crons.ts`.

<Note>
  `Cron` schedules must not use a custom `seconds` field—Convex cron expressions
  only support minute-level granularity. For sub-minute scheduling, use a
  `Duration` interval instead.
</Note>

<Note>
  Non-UTC timezones are not supported by Convex. A schedule with no timezone is
  treated as UTC.
</Note>

<Note>
  `Duration` intervals must be a positive, whole number of seconds, minutes, or
  hours. Sub-second durations (e.g. `Duration.millis(500)`) are not supported.
</Note>

```ts confect/crons.ts
import * as Cron from "effect/Cron";
import * as Duration from "effect/Duration";
import { CronJob, CronJobs } from "@confect/server";
import refs from "./_generated/refs";

export default CronJobs.make()
  .add(
    CronJob.make(
      "clear stale sessions",
      Cron.make({
        minutes: [0],
        hours: [],
        days: [],
        months: [],
        weekdays: [],
      }),
      refs.internal.sessions.clearStale,
    ),
  )
  .add(
    CronJob.make(
      "send weekly digest",
      Cron.parseUnsafe("0 9 * * 1"),
      refs.internal.emails.sendDigest,
    ),
  )
  .add(
    CronJob.make(
      "send hourly reminder",
      Duration.hours(1),
      refs.internal.notifications.sendReminder,
    ),
  )
  .add(
    CronJob.make(
      "payment reminder",
      Cron.parseUnsafe("0 16 1 * *"),
      refs.internal.payments.sendPaymentEmail,
      { email: "billing@example.com" },
    ),
  );
```

`CronJob.make` accepts a unique identifier, a schedule (`Cron`, `Duration`, or `CronWindow`), a ref to an internal mutation or action, and an optional args object matching the ref's args schema. `CronJobs.make()` creates an empty collection; each `.add()` call returns a new `CronJobs` object, so calls can be chained.

## Let Convex choose the minute

Use `CronWindow` when a job can run at any minute within a recurring UTC hour:

```ts confect/crons.ts
import { CronJob, CronJobs, CronWindow } from "@confect/server";
import refs from "./_generated/refs";

export default CronJobs.make().add(
  CronJob.make(
    "payment reminder",
    CronWindow.daily({ hourUtc: 17 }),
    refs.internal.payments.sendPaymentEmail,
    { email: "billing@example.com" },
  ),
);
```

The constructors are `CronWindow.hourly()`, `CronWindow.daily({ hourUtc })`,
`CronWindow.weekly({ dayOfWeek, hourUtc })`, and
`CronWindow.monthly({ day, hourUtc })`. Use UTC hours from 0 to 23,
lowercase weekdays such as `"monday"`, and days of the month from 1 to 31.
Confect uses **`hourUtc`**, not Convex's `hourUTC`.

`CronWindow` is an Effect-style tagged union with `_tag` values `"Hourly"`,
`"Daily"`, `"Weekly"`, and `"Monthly"`. Use `Match.tag` from `effect/Match`
to distinguish variants; lowercase native schedule types appear only in the
Convex export.

These constructors omit the minute rather than choosing one in your application.
For example, `daily({ hourUtc: 17 })` delegates placement within 17:00–18:00 UTC.
An Effect Cron with an unrestricted minute runs every minute instead; a Duration
is an interval, not a calendar window. Use Effect Cron when you need an explicit
minute. `CronWindow` has no local-time-zone option.

Convex validates calendar fields when you add the job. See the
[native supported schedules](https://docs.convex.dev/scheduling/cron-jobs#supported-schedules)
for placement, cadence, and missing-day semantics. Confect does not guarantee
that a deleted and recreated job retains its previously selected minute.

For the full scheduling APIs, see the [Effect `Cron` documentation](https://effect.website/docs/scheduling/cron), the [Effect `Duration` documentation](https://effect.website/docs/data-types/duration/), and the [Convex cron jobs documentation](https://docs.convex.dev/scheduling/cron-jobs).
