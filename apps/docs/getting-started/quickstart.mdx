## Prerequisites

Use Node.js 24 or later and an existing React + TypeScript app. The client examples
below use [Vite](https://vite.dev/guide/) and its `VITE_CONVEX_URL` environment
variable. Run all commands from your app's root directory.

## Installation

<CodeGroup>

```bash pnpm
pnpm add effect@^4 convex @confect/core @confect/server @confect/cli @confect/react
```

```bash npm
npm install effect@^4 convex @confect/core @confect/server @confect/cli @confect/react
```

```bash yarn
yarn add effect@^4 convex @confect/core @confect/server @confect/cli @confect/react
```

```bash bun
bun add effect@^4 convex @confect/core @confect/server @confect/cli @confect/react
```

</CodeGroup>

The commands below use `pnpm exec` to run the locally installed CLIs. With npm,
use `npx` instead; with Yarn, use `yarn`; with Bun, use `bunx`.

## TypeScript configuration

Confect requires `strict: true` in the TypeScript configuration that covers your
Confect files. `exactOptionalPropertyTypes: true` is optional but recommended:

```json tsconfig.json
{
  "compilerOptions": {
    "strict": true,
    "exactOptionalPropertyTypes": true
  }
}
```

See [Effect Schema's explanation of `exactOptionalPropertyTypes`](https://effect.website/docs/v4/schema/introduction#the-exactoptionalpropertytypes-option)
for how it affects optional properties and schema validation.

## Usage

<Steps>
  <Step title="Set up your Convex dev deployment">
    Initialize your development deployment and the `convex/` directory, then exit
    after the first successful sync:

    ```bash
    pnpm exec convex dev --once
    ```

    Follow the prompts to configure your deployment. See Convex's
    [local deployment guide](https://docs.convex.dev/cli/local-deployments) if you
    want to develop locally without an account.

  </Step>

  <Step title="Define your database schema">
    <Note>
      Not every Effect `Schema` is valid for use in Confect. See
      [Schema Restrictions](/concepts/schema-restrictions) for more
      information about what's permitted and what's not.
    </Note>

    Define a table—one file per table under `confect/tables/`, where the **filename is the table name** (so filenames must be valid JS identifiers and may not start with `_`). Each file **must default-export** a `Table`; codegen reads `module.default` and applies the filename as the table name. From other modules (e.g. specs), default-import the codegen-emitted wrapper at `confect/_generated/tables/<name>` to reach the table's derived `Schema`s (`notes.Doc`, `notes.Fields`).

    ```ts confect/tables/notes.ts
    import { Table } from "@confect/core";
    import * as Schema from "effect/Schema";

    export default Table.make(() =>
      Schema.Struct({
        text: Schema.String,
      }),
    );
    ```

    Codegen will assemble every `confect/tables/*.ts` into a `DatabaseSchema` (in `confect/_generated/schema.ts`) and a Convex deploy `SchemaDefinition` (in `confect/_generated/convexSchema.ts`) for you—you never write a `confect/schema.ts`. It also emits a `confect/_generated/id.ts` module exporting a type-safe `Id` constructor (`Id("notes")`) for cross-table references.

  </Step>

  <Step title="Generate your table bindings">
    Before adding a function spec, generate the table schemas and services that
    your specs and implementations will import:

    ```bash
    pnpm exec confect codegen
    ```

    This creates `confect/_generated/`, including `id.ts`, `tables/notes.ts`,
    `schema.ts`, and `services.ts`.

  </Step>

  <Step title="Define your Confect API spec">
    Create a `GroupSpec` and add some functions to it.

    ```ts confect/notes.spec.ts
    import { FunctionSpec, GroupSpec } from "@confect/core";
    import * as Schema from "effect/Schema";

    import { Id } from "./_generated/id";
    import notes from "./_generated/tables/notes";

    export default GroupSpec.make()
      .addFunction(
        FunctionSpec.publicQuery({
          name: "list",
          returns: () => Schema.Array(notes.Doc),
        }),
      )
      .addFunction(
        FunctionSpec.publicMutation({
          name: "create",
          args: () => ({ text: Schema.String }),
          returns: () => Id("notes"),
        }),
      );
    ```

  </Step>

  <Step title="Implement your Confect functions">
    Create a `GroupImpl` and implement its functions. Each spec needs a sibling
    implementation before you run codegen again; otherwise codegen reports a
    missing implementation.

    ```ts confect/notes.impl.ts
    import { FunctionImpl, GroupImpl } from "@confect/server";
    import * as Effect from "effect/Effect";
    import * as Layer from "effect/Layer";

    import databaseSchema from "./_generated/schema";
    import { DatabaseReader, DatabaseWriter } from "./_generated/services";
    import notes from "./notes.spec";

    const list = FunctionImpl.make(databaseSchema, notes, "list", () =>
      Effect.gen(function* () {
        const reader = yield* DatabaseReader;

        return yield* reader
          .table("notes")
          .index("by_creation_time", "desc")
          .collect();
      }).pipe(Effect.orDie),
    );

    const create = FunctionImpl.make(databaseSchema, notes, "create", ({ text }) =>
      Effect.gen(function* () {
        const writer = yield* DatabaseWriter;

        return yield* writer.table("notes").insert({ text });
      }).pipe(Effect.orDie),
    );

    export default GroupImpl.make(databaseSchema, notes).pipe(
      Layer.provide(list),
      Layer.provide(create),
      GroupImpl.finalize,
    );
    ```

    `GroupImpl.finalize` only typechecks once every function declared by the spec has a corresponding `FunctionImpl`, so it acts as a per-group completeness check.

    Generate the function refs and Convex functions now that both the spec and
    implementation exist:

    ```bash
    pnpm exec confect codegen
    ```

  </Step>

  <Step title="Start your Confect app">
    Keep Confect's generated files in sync as you edit:

    ```bash
    pnpm exec confect dev
    ```

    In another terminal, start your Convex dev deployment:

    ```bash
    pnpm exec convex dev
    ```

  </Step>

  <Step title="Call your Confect functions from your React app">

    Set `VITE_CONVEX_URL` in your Vite app's environment to the development
    deployment URL printed by Convex. Set up the Convex React client and provider:

    ```tsx src/main.tsx
    import { ConvexProvider, ConvexReactClient } from "convex/react";
    import React from "react";
    import ReactDOM from "react-dom/client";

    import App from "./App";

    const convexClient = new ConvexReactClient(import.meta.env.VITE_CONVEX_URL);

    ReactDOM.createRoot(document.getElementById("root") as HTMLElement).render(
      <React.StrictMode>
        <ConvexProvider client={convexClient}>
          <App />
        </ConvexProvider>
      </React.StrictMode>,
    );
    ```

    Use Confect's React hooks alongside your Confect public refs to call your Confect functions.

    ```tsx src/App.tsx
    import { QueryResult, useMutation, useQuery } from "@confect/react";
    import * as Array from "effect/Array";
    import { useState } from "react";

    import refs from "../confect/_generated/refs";

    const App = () => {
      const notes = useQuery(refs.public.notes.list, {});

      const createNote = useMutation(refs.public.notes.create);

      const [newNote, setNewNote] = useState("");

      return (
        <div>
          <ul>
            {QueryResult.match(notes, {
              onLoading: () => <p>Loading…</p>,
              onSuccess: (notes) =>
                Array.map(notes, (note) => (
                  <li key={note._id}>{note.text}</li>
                )),
            })}
          </ul>

          <br />

          <textarea
            rows={4}
            cols={50}
            value={newNote}
            onChange={(e) => setNewNote(e.target.value)}
          />
          <br />
          <button
            onClick={() =>
              void createNote({ text: newNote }).then(() => setNewNote(""))
            }
          >
            Create note
          </button>
        </div>
      );
    };

    export default App;
    ```

    Start your React app with its development command (for example, `pnpm dev`
    in a Vite project). Enter a note and click **Create note**. The note should
    appear in the list, confirming that the mutation and reactive query work.

  </Step>
</Steps>
